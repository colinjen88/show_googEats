# Portfolio 圖片風格記錄

> 用於日後開發第 2 套風格樣式的參考。

## 風格 1：Dark Admin Dashboard (目前使用)

### 視覺特徵
- **主色調**：深色背景 (#1a1a1a ~ #0a0a0a)，橘色/金色強調色 (#F59E0B, #EA580C)
- **UI 框架**：Glassmorphism 毛玻璃效果，半透明卡片 + backdrop-blur
- **文字**：白色主文字，灰色 (#9CA3AF) 輔助文字，橘色標題/按鈕
- **按鈕風格**：圓角按鈕，實心橘色 (儲存)、綠色 (密碼/還原)、帶邊框 (登出)
- **佈局**：頂部導航列 + Tab 分頁切換 + 表單區塊
- **邊框**：細邊框 (1px solid rgba(255,255,255,0.1))，圓角容器

### 展示包裝方式
- **Browser Chrome**：模擬瀏覽器視窗 (紅/黃/綠圓點 + 網址列 goodeats.asia/admin)
- **外框**：neo-glass 容器 + 橘色邊框 (border-orange/20)
- **裝飾**：四角落邊框線 + hover 發光效果 (gold/orange glow)
- **Caption**：hover 時顯示底部標籤
